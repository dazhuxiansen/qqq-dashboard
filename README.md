# 纳指轮动大猪V5版

QQQ + TQQQ 纳指回撤分档轮动策略的实时仪表盘（V5）。单文件静态页面，无构建依赖。

**在线访问**：https://dazhuxiansen.github.io/qqq-dashboard/

## 功能

- **回撤温度计**：0 ~ -16% 渐变彩条 + 5 档刻度 + 当前位置标记
- **距触发进度条**：实时显示距离下一档触发还有多远
- **一键复制挂单**：复制当档挂单参数（价格/数量/标的）
- **盘中预警**：距触发位 ≤ 0.5% 时卡片呼吸高亮 + 标题闪烁
- **触发历史日志**：基于真实历史数据重放的档位切换记录
- 腾讯财经实时行情，每 60 秒自动刷新
- 账户设置（金额/汇率/档位）保存在浏览器本地

## 数据说明

- 行情源：腾讯财经 qt.gtimg.cn（CORS 开放，支持跨域直连）
- 日线数据：页面内置，更新至 2026-10-22 收盘
- 本页面不收集任何数据，所有计算在浏览器本地完成

## 本地使用

直接用浏览器打开 `index.html` 即可，无需服务器。
